# 宗族纪事 V0.0.1

Godot 4.6 基础数据与 UI 原型，无第三方插件、无网络依赖、无外部美术素材。

## 启动
1. 解压整个文件夹。
2. 打开 Godot 4.6，在项目管理器选择「导入」。
3. 选择本文件夹中的 `project.godot`，打开工程。
4. 按 F6（打开 main.tscn 时）或 F5 运行。推荐 F5。

界面使用操作系统已有的中文字体（例如 Windows 微软雅黑、macOS 苹方、Linux Noto Sans CJK），没有附带字体文件。如出现方框，请先安装可用的中文字体。

## 已实现
- 360 日简化历法，每月 30 日；手动推进日、月、年；自动推进三档速度，默认暂停。
- 24 名在册成员、3 房、6 户、1 位历史先祖；年龄随日期计算。
- 宗族总览、人物名册（六维能力及亲属关系）、房支家庭、简化家谱、财产账簿。
- 公共与家庭财产分别统计。初始公共田地 80 亩、家庭田地共 240 亩。
- 单槽 JSON 存档/读档（`user://clan_save.json`），新开局不删除旧存档。

## 文件结构
- `project.godot`: 工程配置，World 为 Autoload。
- `core/world.gd`: 世界数据、日期、基础查询、存档。
- `data/scenario.json`: 初始测试剧本，可编辑数值（请保持 ID 关联）。
- `ui/main.tscn`: 主场景。
- `ui/main.gd`: 运行时 UI 构建和交互。
- `tests/check_scenario.py`: 可选的 Python 3 初始数据一致性测试。

## 手动验收
1. F5 后显示 24 人、3 房、6 户；公库 200 贯、储粮 100 石。
2. 点击 +1年，日期进入承平二年，人物年龄增加 1。
3. 人物名册点击沈文博，父亲显示沈承德，配偶显示许氏。
4. 财产账簿显示公产 80 亩、全族关联田地 320 亩。
5. 存档，推进一年，再读档：日期恢复。新开局恢复初始日期。
6. 切换自动推进速度，点击继续与暂停，确认日期变化。

## 限制与下一步
此版本仅提供组织、时间与数据展示基础，不包含生育、死亡、继承、产业生产、真实地图、AI、财产交易或完整权限系统。六维能力是测试数值。存档仅有基本结构校验，不支持任意损坏文件恢复。数据模型暂用 JSON + Dictionary，以便快速迭代；后续可逐步迁移至类型化实体与独立模拟系统。

交付环境无 Godot 可执行程序，未进行引擎编译或运行测试；已提供数据一致性测试和手动验收步骤。

下一迭代建议：独立产权与账户、土地/田庄实体、每月经济结算、纪事流水。
